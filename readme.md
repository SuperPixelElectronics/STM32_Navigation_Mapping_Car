# STM32 建图导航小车
## 简介
![](./pictures/cover.png)
这是我基于 STM32F103C8T6 开发的一款可自主建图与导航的微型智能小车。小车尺寸极为紧凑，仅 5×6 厘米，可轻松置于掌心。它配备有配套的遥控器。启动后，小车能够通过遥控器接收运动指令，同时利用自身搭载的编码器、MPU6050 和磁力计融合计算出准确的里程计信息，获得实时位姿。随后，结合车上的激光测距传感器探测障碍物位置，计算障碍物位置并逐步构建环境地图。当用户通过遥控器指定目标点后，小车的路径规划模块会计算出一条无碰撞的最优路径。接着，轨迹跟踪模块通过运动学逆解，将路径指令分解为左右轮的目标速度，最终通过PI速度环驱动电机，使小车自主、平稳地驶向目标点。<br>

在这几年中，我为了比赛，和队友一起先后搭了好多辆小车，可是由于每次都是临时搭建，准备时间少，基础不牢，往往小车功能都十分简陋，只能巡线避障或完成题目的业务逻辑，好多场比赛也失利了。但是在这期间我被ROS小车的导航和建图吸引了，大二的暑假我开始捣鼓ROS小车。在分析轮趣的ROS小车工程的时候，我被深深的震撼了，这个小车的功能不是完成比赛的特定要求，而是能够在一个不确定的现实生活中，通过建图和导航等手段，准确地前往目标点，这才是小车在现实生活中最实用的功能！可是，当我想了解建图和导航算法的时候，我发现在ROS小车中，编写者为了简便开发，直接调用了ROS的成品节点来实现，导致我只能看到一个黑盒子，却不知道里面是怎么实现的。刚好我想做一个尽可能小的迷你小车，这样可以随处把玩。由于受到尺寸的限制，只能使用MCU。由于这是我的支线项目，我不打算花太多时间，于是我想只用MCU来实现简易的建图和导航算法，集成到这个迷你小车里面，于是这个小车就诞生了。<br>
